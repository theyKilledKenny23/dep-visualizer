# Dep-Visualizer

## Общее описание

Инструмент визуализации графа зависимостей для менеджеров пакетов.
На текущем этапе (Этап 1) реализован минимальный прототип CLI-приложения 
с загрузкой и валидацией конфигурации из JSON-файла.

Готовые средства (менеджеры пакетов, библиотеки) для получения зависимостей 
не используются. Все операции конфигурации и валидации выполняются 
собственными средствами языка Python.

## Функции и настройки

### Параметры конфигурации (`config.json`)

| Параметр             | Тип      | Описание                                              |
|----------------------|----------|-------------------------------------------------------|
| `package_name`       | string   | Имя анализируемого пакета                             |
| `repository_url`     | string   | URL-адрес репозитория (например, PyPI API)            |
| `test_mode`          | boolean  | Режим работы с тестовым репозиторием (true/false)     |
| `test_repo_path`     | string   | Путь к файлу тестового репозитория (если test_mode)   |
| `output_image`       | string   | Имя сгенерированного файла с изображением графа       |
| `max_depth`          | integer  | Максимальная глубина анализа зависимостей (>= 1)      |
| `filter_substring`   | string   | Подстрока для фильтрации пакетов                      |

### Обработка ошибок

Приложение проверяет:
- Существование и валидность JSON-файла.
- Наличие всех обязательных ключей.
- Соответствие типов данных (строки, целые числа, булевы значения).
- Логическую корректность (например, `max_depth` >= 1, наличие `test_repo_path` при `test_mode: true`).

При обнаружении ошибки приложение выводит понятное сообщение и завершается с кодом `1`.
